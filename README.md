📌 Blinkit Excel Dashboard Project

This project is a fully interactive Excel Dashboard built using the Blinkit Grocery Sales dataset.
It includes slicers, charts, KPIs, and a professional UI design.

📊 Project Features

✔ Interactive slicers (Outlet Size, Outlet Type, Item Type)

✔ KPI Cards (Total Sales, Avg Sales, Number of Items, Ratings)

✔ Pie Charts, Bar Charts, and Trend Graphs

✔ Clean UI inspired by Blinkit brand theme

✔ Filter Panel with custom-designed slicer styles

✔ Modern dashboard layout for data analysis

🛠 Tools Used

->Microsoft Excel

->Pivot Tables

->Pivot Charts

->Custom Slicer Styles

->Conditional Formatting

->Excel Shapes & Icons

📈 Dashboard Preview

A snapshot of the dashboard is provided in the repository.

🎯 Purpose of This Project

Analyze Blinkit grocery sales and outlet performance
Demonstrate skills in Excel dashboard creation
Visualize key metrics for decision-making

🚀 How to Use

Download the Excel file
Open the dashboard sheet
Use the slicers to interact with the data
